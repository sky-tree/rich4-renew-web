## 清理边界

清空旧测试房间和中继分配需要重启独立候选的 party/TURN 服务，会断开现有测试对局。旧候选目录移入服务器私有归档，活动发布目录保留本次长测版、`0a1ed20` 和 `a128f6a` 回滚基线。移除已核实的临时上传包及本任务启动的本地测试服务；保留脱敏验收证据。

不得清除玩家浏览器存档、私有素材、登录账号、TURN 密钥、既有正式版本或其他任务的 Git 工作区。访问日志保留在服务器私有归档。源码同步到本分支，不强制覆盖服务器已有分支。

## 长测操作

1. 完成旧对局后关闭旧页面，重新打开固定入口；首页核对 `v0.6.7-longtest.1` 及发布记录中的 Git 编号。
2. 建立新房间，确认所有设备成员及聊天互通，再开局。长测期间保留页面；不以清除缓存/存档作为常规恢复步骤。
3. 发现缺图、操作停滞或不同步时，记录版本、设备/浏览器、网络类型、日期、操作步骤与断网时长。不要提供密码或会话 cookie。
4. 优先观察弱网、长局及凭据到期后的重连。既有 Peer 的 TURN 配置续期尚未证明，不能据短测成功判定长局稳定。
