# 01 · 产品范围、目标与发布边界

## 1. 产品定位

Rich4 Renew Web 是基于 `iam567/rich4-renew-app` Fork 的高清浏览器游戏版本。用户通过 HTTPS 页面直接进入游戏，支持桌面和移动浏览器，无须安装 App。以重用现有成熟玩法与规则为前提，优化画面性能、资源传输及网页交互体验。

### 核心体验目标

- 桌面浏览器：键鼠正常操作、地图可缩放/旋转、游戏界面完整、长局运行稳定。
- 移动浏览器：触屏可操作、横竖屏适配、后台恢复后能读取存档。
- 单机：保留原有规则、AI、卡片、道具、股票、天气、事件、建筑与统计。
- 新模式：保留五城市十二人的大富豪模式、歌舞伎町玩法及相关内容。
- 派对：在有权限和可用信令服务的情况下，保留 WebRTC 房间、输入同步及断线恢复能力。
- 资源：按需加载，能够清楚显示下载进度、失败原因和重试入口。

### 非目标（v1 不做）

- 不做 Godot/C++/Unity 规则引擎整体移植。
- 不做 Android APK、iOS IPA、Electron 二进制包。
- 不重新编写全部 UI 为 Vue/React，也不将 Vue 用作 Canvas 绘制替代品。
- 不引入 Spring Boot 作为单机规则后端，不做服务器端每帧/每回合权威计算。
- 不重做地图编辑器、付费、账号中心、排行榜及全量云存档。
- 不承诺兼容原版二进制素材与旧存档；现有 Fork JSON 存档格式迁移应遵循显式版本策略。
- 不在没有素材许可前开放第三方商业资源的公众下载。

## 2. 用户场景与验收故事

| 编号 | 用户场景 | 通过标准 |
| --- | --- | --- |
| U-01 | 首次访问网页进入标题界面 | 页面可交互；核心资源请求成功；不要求下载其他地图全部素材 |
| U-02 | 选择普通地图开始双人/多人 AI 对局 | 掷骰、移动、买地、事件与胜负流程正确 |
| U-03 | 切换 2D 地图缩放与旋转 | 画面可见区域、遮挡、触摸位置一致，无明显跳闪 |
| U-04 | 运行大富豪模式并跨城 | 十二人及五城市规则与存档恢复正常 |
| U-05 | 浏览器保存/关闭/重进 | 手动及自动存档可恢复，损坏文件给出明确错误 |
| U-06 | 使用手机访问 | 菜单和按钮可触达，画面横竖屏自适应 |
| U-07 | 朋友跨网络进入派对房间 | 显示连接状态；输入顺序保持一致；断线有恢复或明确失败提示 |
| U-08 | 访问失效或缺失的图片 | 可重试或降级，不出现永久黑屏/无提示等待 |
| U-09 | 网站发布新版本 | 老页面不会混用新旧资源；存档不因部署消失 |

## 3. 首版最小可交付范围（MVP）

**必须**：纯 Web 构建、合法素材下至少一张地图可玩、完整单机循环、IndexedDB 存档、PC+Android Chrome+iOS/iPadOS Safari 基本回归、Nginx 测试环境、资源加载进度与失败提示。

**允许推后**：全部地图最优性能、WebGL 替换、完整离线/PWA、多端存档同步、自建联机信令与 TURN（如暂不开放派对，入口需禁用并明确告知）。

**发布门槛**：即使技术验收完成，也不能把未确认分发许可的游戏素材发布到公共域名；可以在受控开发环境或仅使用已获授权/自有素材进行功能验证。

## 4. 代码与素材的授权分离

- 根目录 `LICENSE`：源码为 **GPL-3.0-or-later**。修改分发时应保留许可、版权声明，并遵守相应源码提供义务；具体合规方案发布前复核。
- `README.md`、`THIRD_PARTY.md` 明确：游戏原始资源、音视频、高清重绘不因代码的 GPL 许可证而获得公开分发授权，原作者发布的资源包标示为私人使用。
- **Fork 不等于获得上述素材的公开托管权限**。不能因资源可下载而视为可用于对公众提供游戏服务。
- 方案 A：取得素材权利方明确授权；方案 B：使用自制/已授权素材替换；方案 C：评估合法的用户端导入方式并由法律评审确认；不能仅靠免责声明或登录限制解决授权。
- 公网测试资源发布前需要“素材清单 + 授权证明 + 责任人批准”的闸门；第三方品牌/名称/人物形象等也需单独审查。

## 5. 质量原则

1. **功能正确性优先**：性能优化不能悄悄更改规则、动画触发时机或命中范围。
2. **首屏轻量**：避免为打开首页下载所有高清地图。
3. **少新增依赖**：先复用既有 DOM、Vite、Vitest 和 Game 模型。
4. **可回滚**：渲染器、素材清单、部署版本均保留切换/回退机制。
5. **测量驱动**：FPS、内存和下载体积需在同设备同场景下比较；指标只设目标，不伪造测试结果。
